# Variantes revisadas: consecuencia

2026-09-07. Lote acotado: una alternativa nueva por idioma para el ejemplo del proyecto retrasado. Las frases completas están en `tests/result_variants_cases.mjs`; no se aplican sustituciones globales de conectores.

## Criterio

Se conserva el proyecto como sujeto/tema, el retraso y la referencia a una consecuencia anterior. Estos conectores pueden variar en matiz o registro: no se declaran intercambiables en cualquier oración. Se admiten para la consigna libre «Como resultado, el proyecto se retrasó», no para dictado, copia, transcripción, transformación ni bloques. Una política explícita distinta de `meaning` desactiva las equivalencias compartidas; las respuestas que el autor enumere explícitamente siguen siendo válidas.

La aceptación es una decisión editorial limitada a estas frases, contrastada con las siguientes referencias sobre los conectores; las fuentes no certifican el curso ni evalúan nuestras oraciones completas:

- Inglés, therefore/consequently/as a result: [Cambridge University Press](https://assets.cambridge.org/97811088/11330/excerpt/9781108811330_excerpt.pdf).
- Francés, en conséquence: [Larousse](https://www.larousse.fr/dictionnaires/francais/cons%C3%A9quence/18363).
- Alemán, infolgedessen: [Duden](https://www.duden.de/rechtschreibung/infolgedessen).
- Italiano, pertanto: [Treccani](https://www.treccani.it/vocabolario/pertanto/).
- Portugués, por isso/por consequência: [Priberam](https://dicionario.priberam.org/por%20consequ%C3%AAncia).
- Ruso, поэтому: [Gramota](https://gramota.ru/poisk?mode=slovari&query=%D0%9F%D0%BE%D1%8D%D1%82%D0%BE%D0%BC%D1%83).
- Chino, 因此: [Ministerio de Educación de Taiwán](https://dict.concised.moe.edu.tw/dictView.jsp?ID=41944&la=0&powerMode=0).
- Japonés, そのため: [material didáctico de 3A Network](https://www.3anet.co.jp/np/secure/0-0001-03-301000/0-0001-03-301000-0.pdf).
- Coreano, 그래서: [Diccionario básico del Instituto Nacional de la Lengua Coreana](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?mainSearchWord=%EA%B7%B8%EB%9E%98%EC%84%9C&nation=eng).
- Árabe, لذلك: [Britannica/Merriam-Webster](https://arabic.britannicaenglish.com/therefore).

## Evaluación y audio

Las pruebas comprueban aceptación en traducción/pregunta abierta/turno de diálogo y rechazo de una negación que cambia el resultado. También comprueban que los tipos de reproducción exacta no admitan estas paráfrasis.

La interfaz distingue la respuesta alternativa aceptada del modelo original sobre el que trata la explicación. El botón de audio identifica ese modelo original: no afirma reproducir la variante escrita por el alumno. No se crearon ni se necesitan audios nuevos para aceptar estas respuestas. Si las variantes se convierten en ejemplos enseñados con reproducción propia, habrá que proporcionar audio revisado, mediante TTS si hace falta.

Quedan por revisar otras intenciones, niveles, registros y formulaciones: una lista finita no es una evaluación semántica general.
