Fecha: 2026-09-09. La reorganización del caso coreano quedó aplicada; se conserva la lista de criterios para revisar los demás sistemas de escritura.

En `library/courses/Korean/units/hangul-foundations.json` se corrigió:

## Criterios para la próxima reorganización

1. Separar presentación visual del sistema, enseñanza de sonidos, composición de sílabas y evaluación de lectura.
2. Antes de exigir lectura productiva de un bloque, enseñar los componentes y las reglas necesarias para ese ejemplo; no exigir memorizar todo el alfabeto primero.
3. Antes de una comparación auditiva, enseñar los sonidos contrastados. La consigna no debe revelar gráficamente la respuesta si se pretende evaluar escucha.
4. Distinguir sonido de una letra, nombre de la letra y sonido dentro de una sílaba. No asumir que TTS de un carácter aislado devuelve el sonido requerido.
5. Recorrer como principiante las actividades reorganizadas, incluyendo errores plausibles y la ayuda que recibe el alumno. No resolver únicamente con la clave de respuestas del archivo.
6. Revisar los diez cursos con este criterio, sin asumir que comparten sistema de escritura o requieren idéntica secuencia.
